# 🎂 Sitio de Cumpleaños — Valeria

## Cómo agregar la música

1. Coloca tu archivo de audio aquí:
   ```
   assets/music/canserbero_stupid_love_story.mp3
   ```
2. El nombre del archivo debe ser exactamente ese (respeta mayúsculas y espacios).

## Cómo ver el sitio localmente

Simplemente abre `index.html` en tu navegador.  
> ⚠️ **Nota:** Para que el audio funcione correctamente en local, se recomienda usar una extensión como **Live Server** en VS Code, ya que algunos navegadores bloquean el audio en el protocolo `file://`.

## Cómo subirlo a GitHub Pages

1. Sube todos los archivos al repositorio en la rama `main`.
2. Ve a `Settings → Pages` y selecciona la rama `main`.
3. Tu sitio estará disponible en `https://tuusuario.github.io/nombre-repo`.

## Estructura del proyecto

```
cumpleanos/
├── index.html       ← Estructura HTML
├── style.css        ← Estilos y animaciones
├── script.js        ← Lógica interactiva
└── assets/
    ├── music/
    │   └── canserbero_stupid_love_story.mp3  ← ¡Agregar aquí!
    └── icons/
```
